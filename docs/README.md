# AI Motion PoC

AI Motion Proof of Concept

本專案為《羽球+1》AI Motion 模組。

目的：

利用 Computer Vision 分析羽球動作，
建立可解釋（Explainable）的動作分析系統。

---

## Current Progress

- [x] OpenCV
- [x] MediaPipe Pose
- [x] 33 Landmark
- [x] Knee Angle
- [x] Pelvis Center
- [x] Pelvis Trajectory
